Lecture 5: CSS Selectors

What are CSS Selectors?

CSS selectors are used to select HTML elements that we want to style. They tell CSS which HTML elements should receive specific styles.

1. Element Selector

The element selector selects HTML elements based on their tag name.

For example, the h3 selector selects all h3 elements and applies the specified style to them.

This heading uses the Element Selector.

2. Class Selector

The class selector selects HTML elements that have a specific class attribute. A class selector starts with a dot (.).

This paragraph uses the Class Selector.

3. ID Selector

The ID selector selects one specific HTML element using its id attribute. An ID selector starts with a hash symbol (#).

This paragraph uses the ID Selector.

4. Universal Selector

The universal selector is represented by an asterisk (*). It selects all HTML elements on the webpage.

Example: * { box-sizing: border-box; }

5. Attribute Selector

The attribute selector selects HTML elements based on their attributes or attribute values.

For example, input[type="text"] selects input elements whose type attribute is text.

6. Grouping Selector

The grouping selector is used to apply the same style to multiple HTML elements. Multiple selectors are separated by a comma.

This heading is styled using the Grouping Selector.

Example: h2, h4 { color: purple; }

7. CSS Combinators

CSS combinators are used to define a relationship between two or more HTML elements.

Descendant Combinator

The descendant combinator selects elements that are inside another element. It is represented by a space.

Child Combinator

The child combinator selects elements that are direct children of another element. It is represented by >.

Adjacent Sibling Combinator

The adjacent sibling combinator selects the element that comes immediately after another element. It is represented by +.

The general sibling combinator selects all matching sibling elements that come after another element. It is represented by ~.
