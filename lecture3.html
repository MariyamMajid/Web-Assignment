Lecture 3: HTML Forms and Tables

HTML Forms

An HTML form is used to collect information from users. Forms can contain different input fields and controls.

Form Tag

The form tag is used to create a form on a webpage. It contains different form elements used to collect information from the user.

Fieldset and Legend

The fieldset tag is used to group related form elements. The legend tag is used to give a title or description to the group.

Input Fields

The input tag is used to create different types of fields where users can enter or select information.

Text Field

A text field allows the user to enter simple text, such as a name.

Password Field

A password field is used to enter a password. The entered characters are hidden.

Email Field

An email field is used to enter an email address.

Checkbox

A checkbox allows the user to select one or more options from a list.

Radio Button

A radio button allows the user to select one option from a group of options.

Submit Button

A submit button is used to submit the information entered in a form.

HTML Tables

HTML tables are used to organize and display data in rows and columns.

Table Tags

Table Tag

The table tag is used to create an HTML table.

Table Row Tag

The tr tag is used to create a row in a table.

Table Header Tag

The th tag is used to create a heading or header cell in a table.

Table Data Tag

The td tag is used to add data inside a table cell.

Rowspan

The rowspan attribute is used to combine two or more rows into one cell.

Colspan

The colspan attribute is used to combine two or more columns into one cell.

Cell Padding

Cell padding is the space between the content of a cell and the cell border.

Cell Spacing

Cell spacing is the space between the cells of a table.
