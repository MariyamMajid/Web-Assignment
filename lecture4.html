Lecture 4: Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML webpages. CSS controls the appearance, colors, fonts, spacing, and layout of webpage elements.

Why Do We Use CSS?

CSS is used to make webpages more attractive and organized. It helps us change the color, size, font, background, spacing, and other visual properties of HTML elements.

CSS Syntax

CSS uses a selector followed by a property and its value.

Example: p { color: purple; }

Types of CSS

There are three common ways to apply CSS to an HTML webpage: Inline CSS, Internal CSS, and External CSS.

1. Inline CSS

Inline CSS is written directly inside the HTML element using the style attribute.

This paragraph is styled using Inline CSS.

2. Internal CSS

Internal CSS is written inside the style tag in the head section of an HTML document.

This paragraph is styled using Internal CSS.

Style Tag

The style tag is used to write internal CSS. It is normally placed inside the head section of the HTML document.

3. External CSS

External CSS is written in a separate CSS file. The CSS file can be connected to an HTML document using the link tag.

In this website, the external CSS file is named style.css.

Link Tag

The link tag is used to connect an external CSS file with an HTML document.

Example: <link rel="stylesheet" href="style.css">

Difference Between CSS Types

Inline CSS is written inside an HTML element. Internal CSS is written inside the style tag. External CSS is written in a separate CSS file.

Summary

In this lecture, we learned what CSS is and why it is used. We also learned CSS syntax and the three ways of applying CSS: Inline CSS, Internal CSS, and External CSS. We also learned about the style tag and link tag.
