Lecture 2: HTML Basics

What is HTML?

HTML stands for HyperText Markup Language. It is used to create and structure the content of webpages.

Basic HTML Structure

An HTML document has a basic structure that includes the html, head, and body sections.

HTML Tag

The html tag is the main container of an HTML document.

Head Tag

The head section contains information about the webpage, such as its title and other settings.

Body Tag

The body section contains the content that is displayed on the webpage.

HTML Headings

HTML provides six levels of headings, from h1 to h6. The h1 heading is the largest and most important heading.

HTML Paragraph

The paragraph tag is used to display text in paragraph form.

Text Formatting

HTML provides different tags for formatting text.

This text is bold.
This text is italic.
This text is underlined.

Line Break

The br tag is used to move the content to the next line without starting a new paragraph.

Images in HTML

Images can be added to a webpage using the img tag. The src attribute is used to specify the image location.

Summary

In this lecture, we learned about HTML, its basic structure, headings, paragraphs, text formatting, line breaks, and adding images to webpages.
